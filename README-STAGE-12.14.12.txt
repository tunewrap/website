TUNEWRAP — STAGE 12.14.12
SITE AUTO-TRANSLATE COMPLETION

ПРОБЛЕМА

Кнопка «Автоперевести язык» отправляла весь текст каждого поля одним
элементом. Длинные «Условия использования» превышали лимит API, а многострочные
поля не соответствовали однострочному контракту переводчика.

Поэтому EN успевал перевестись частично, затем цикл падал на длинном
тексте и до UA / GE / DE уже не доходил.

ЧТО ИСПРАВЛЕНО

- длинные тексты делятся по абзацам, предложениям и безопасному лимиту;
- переносы строк и пустые абзацы сохраняются;
- каждый язык EN / UA / GE / DE выполняется независимо;
- ошибка одного языка не останавливает остальные;
- язык попадает в админку только после полного перевода всех его частей;
- постоянная строка статуса показывает прогресс и точный итог;
- при частичном успехе указываются готовые и неготовые языки;
- временные 429 / 502 / 503 / 504 повторяются один раз.

УСТАНОВКА

Распакуйте ZIP в корень website и выполняйте по одной:

node scripts/install-stage-12.14.12-site-autotranslate-completion.js
npm.cmd test
npx.cmd wrangler pages functions build

После сборки удалите из Changes только _worker.bundle, закоммитьте
остальные файлы, Push origin и дождитесь зелёного Cloudflare.

ПОСЛЕ ПУБЛИКАЦИИ

В Admin Studio → Сайт:
1. выберите RU;
2. нажмите «Автоперевести язык»;
3. дождитесь строки «Переведено: EN, UA, GE, DE»;
4. нажмите «Сохранить изменения».

D1 migration: not required.
