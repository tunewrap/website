TUNEWRAP — STAGE 12.14.9
MOBILE AUTO UPDATE

ЧТО ИСПРАВЛЕНО

На телефоне Chrome мог восстановить старую вкладку из памяти (BFCache) вместе
со старым HTML и JavaScript. Поэтому новые треки и изменения из Admin/D1 не
появлялись, хотя Cloudflare уже был зелёным и сайт был обновлён.

Stage 12.14.9:

1. Проверяет новую версию сайта при возврате в мобильную вкладку, после
   восстановления страницы, возвращения сети и периодически в открытой вкладке.
2. Отдельно сравнивает актуальные данные D1: треки, цены, Site CMS, категории
   историй и настройки звучания. Изменения Admin видны без нового Git-деплоя.
3. Автоматически обновляет страницу, только если это безопасно.
4. Никогда не прерывает играющую песню и не стирает заполненную форму. В этом
   случае показывает кнопку «Обновить сейчас» на выбранном языке.
5. HTML, JS и CSS всегда перепроверяются у Cloudflare.
6. Долгий кэш R2 для MP3 и обложек не изменён — медиа не скачиваются заново без
   необходимости.

УСТАНОВКА

Распакуйте ZIP прямо в корень папки website с заменой/добавлением файлов.
Затем в PowerShell, находясь в папке website, выполняйте команды по одной:

node scripts/install-stage-12.14.9-mobile-auto-update.js
npm.cmd test
npx.cmd wrangler pages functions build

После успешной сборки:

1. В GitHub Desktop удалите из списка изменений только _worker.bundle через
   Discard Changes.
2. Закоммитьте остальные файлы и отправьте их в main.
3. Дождитесь зелёного Cloudflare Pages.

ВАЖНО ДЛЯ ПЕРВОЙ ПРОВЕРКИ НА ТЕЛЕФОНЕ

Старая вкладка Stage 12.14.8 ещё не содержит новый механизм. После первого
деплоя 12.14.9 один раз закройте старую вкладку сайта и откройте сайт заново
(или выполните обычное обновление страницы). Начиная с 12.14.9 дальнейшие
версии и изменения Admin/D1 будут обнаруживаться автоматически.

ПРОВЕРКА

1. Откройте сайт на телефоне и оставьте вкладку открытой.
2. Добавьте/измените трек или текст в Admin и опубликуйте.
3. Вернитесь в мобильную вкладку. Если песня не играет и форма не заполнена,
   страница обновится сама. Иначе появится безопасная кнопка обновления.

D1 migration: not required.
