TUNEWRAP WEB — STAGE 12.3: FULL SITE CMS

ЦЕЛЬ
Закрыть вопрос редактирования публичного сайта через Admin Studio.

После Stage 12.3 структура Admin Studio:
Музыка | Заказы | Стоимость | Сайт

ГДЕ ЧТО РЕДАКТИРУЕТСЯ
Музыка:
- треки, обложки, аудио, тексты песен и переводы.

Заказы:
- заявки клиентов и статусы.

Стоимость:
- цены, названия и содержимое обычных/свадебных пакетов.

Сайт:
- главная и Hero;
- Философия TuneWrap;
- Как это работает;
- заголовки музыкальных историй;
- заголовки авторских;
- вход в форму заказа;
- основные подписи формы;
- корпоративная панель;
- Контакт-центр;
- WhatsApp / Telegram / Instagram / TikTok / YouTube / Email;
- основной канал «Написать нам»;
- информационные карточки способов оплаты;
- Условия использования;
- footer/location.

КОНТАКТЫ
У каждого канала есть:
- показывать / скрыть;
- подпись;
- номер / username / email / URL;
- прямая ссылка.

Если прямая ссылка пустая:
- WhatsApp строится из номера;
- Telegram строится из @username;
- Email строится из email.

Настроенные WhatsApp / Telegram также используются в готовой заявке.
Основной канал применяется к «Написать нам» и корпоративной кнопке.

СПОСОБЫ ОПЛАТЫ
Можно добавлять и удалять информационные карточки:
- название;
- короткое описание;
- примечание;
- ссылка;
- порядок;
- показывать / скрыть.

ВАЖНО:
это НЕ подключение реального платежного шлюза.
Это редактируемые карточки интерфейса.
TBC / Stripe / PayPal и фактическую оплату подключаем отдельно.

УСЛОВИЯ ИСПОЛЬЗОВАНИЯ
В Admin есть:
- заголовок;
- вступление;
- полный текст.

Пока полный текст пустой, ссылка «Условия использования» на публичном сайте остаётся неактивной.
После добавления текста и сохранения ссылка автоматически становится активной и открывает modal.

ЯЗЫКИ
RU / UA / GE / EN / DE.
Есть существующий Workers AI автоперевод.
Перевод идёт чанками по 8 элементов — та же безопасная схема, что уже используется в TuneWrap.

БЕЗОПАСНОСТЬ / СТАБИЛЬНОСТЬ
- Site Admin API защищён существующим Cloudflare Access;
- запись дополнительно проверяет same-origin;
- публичный API только читает;
- нет MutationObserver;
- не создаётся новый Audio;
- Track Catalog / Global Queue / D1 music / R2 music не меняются;
- Pricing CMS не дублируется;
- если /api/site-content временно недоступен, остаётся встроенный текст сайта.

УСТАНОВКА

1. Распаковать ZIP поверх корня website с заменой.

2. Обновить Admin navigation:
   node scripts/install-site-admin-nav.js

3. D1 remote:
   npx.cmd wrangler d1 execute tunewrap-catalog --remote --file=./migrations/0005_site_content_cms.sql

4. Проверка D1:
   npx.cmd wrangler d1 execute tunewrap-catalog --remote --command="SELECT id, schema_version, updated_at, last_edited_by FROM site_content_config;"

5. Тесты:
   npm.cmd test

6. Build:
   npx.cmd wrangler pages functions build

7. GitHub Desktop Summary:
   Stage 12.3 – Full Site CMS

8. После зелёного Cloudflare:
   /admin/site.html

ПЕРВАЯ БЕЗОПАСНАЯ ПРОВЕРКА
Не менять сразу весь сайт.
Изменить только:
Контакты → Telegram → подпись или ссылку,
либо Contact Hub subtitle.
Сохранить → Ctrl+F5 публичного сайта → проверить.

ПРИМЕЧАНИЕ ПО ТЕКСТАМ
*текст* в некоторых полях используется как безопасный визуальный акцент/курсив.
Переносы строк в textarea сохраняются там, где Site CMS реально перерисовывает поле.

ПРИМЕЧАНИЕ ПО LEGAL
Stage 12.3 создаёт редактируемый блок «Условия использования», но не пытается автоматически сочинить юридические условия.
Юридический текст лучше отдельно подготовить/проверить под фактическую юрисдикцию и способы оплаты.
