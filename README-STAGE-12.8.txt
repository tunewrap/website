TUNEWRAP WEB — STAGE 12.8
GIFT CERTIFICATE OVERLAY

Что меняется:
- «Подарочный сертификат» открывает отдельное плавающее окно поверх сайта.
- Сайт остаётся виден по краям.
- Окно закрывается крестиком, по фону и Esc.
- Внутри показываются все активные пакеты из Pricing CMS:
  3 обычных + 3 свадебных.
- Названия и цены берутся из Admin → Стоимость, не захардкожены.
- Выбранная карточка подсвечивается.
- После «Продолжить с сертификатом» используется существующий CRM-поток сертификата.

Упрощённая форма сертификата:
- остаются пакет/стоимость, имя покупателя, контакт;
- скрываются стиль, инструменты, вокал, повод, история, описание, дополнительные вопросы и срочность;
- есть кнопка «Изменить пакет», которая снова открывает окно.

Важно:
- свадебный пакет, купленный как сертификат, остаётся типом certificate в Orders CRM;
- получатель рассказывает детали песни позже;
- RU / UA / GE / EN / DE поддерживаются;
- D1 migration НЕ НУЖНА;
- плеер, очередь, Music CMS, Story Categories, Corporate и Terms не меняются.

Установка:
1. Распаковать ZIP поверх корня website.
2. node scripts/install-stage-12.8-gift-certificate-overlay.js
3. node scripts/gift-certificate-overlay-test.js
4. npm.cmd test
5. npx.cmd wrangler pages functions build
6. Restore _worker.bundle.
7. GitHub Desktop Summary:
   Stage 12.8 – Gift Certificate Overlay
8. Commit to main → Push origin.

Production test:
A. Нажать «Подарочный сертификат».
B. Проверить 6 карточек.
C. Выбрать любой пакет, например Wedding Collection.
D. Нажать «Продолжить с сертификатом».
E. В форме должны остаться только пакет/стоимость + имя + контакт.
F. Сформировать тестовую заявку и проверить Admin → Заказы.
