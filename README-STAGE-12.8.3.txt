TUNEWRAP WEB — STAGE 12.8.3
RIGHT-SIDE CLOSE UX

Что пересмотрено

1. АНКЕТА
Проблема:
кнопка закрытия находилась слева сверху и выглядела как отдельная навигация.

Теперь:
- закрытие находится ПРЯМО ВНУТРИ карточки анкеты;
- позиция: справа сверху;
- desktop/tablet: X + «Закрыть анкету»;
- phone: заметный круглый X справа сверху;
- старый левый «Назад к выбору» визуально скрыт;
- при нажатии используется его уже проверенная логика, поэтому сценарий формы не переписан.

2. МУЗЫКАЛЬНЫЕ ИСТОРИИ — ПОЛНАЯ БИБЛИОТЕКА
Проблема:
«Назад» находилось слева сверху.

Теперь topbar:
[тип библиотеки]        TuneWrap        [X Закрыть]

То есть закрытие всегда справа.

3. АВТОРСКАЯ БИБЛИОТЕКА
Точно такая же схема:
[Авторские]             TuneWrap        [X Закрыть]

4. МОБИЛЬНАЯ ВЕРСИЯ
Отдельно предусмотрено <=620px:
- у анкеты круглый X справа сверху;
- у обеих библиотек круглый X справа сверху;
- TuneWrap остаётся по центру;
- название раздела остаётся слева;
- текст «Закрыть» визуально скрывается на маленьком экране, но остаётся aria-label.

5. ЧТО НЕ ТРОГАЕМ
- Catalog Runtime как владелец открытия/закрытия библиотек;
- scroll restoration;
- Orders;
- Pricing;
- сертификат;
- Player;
- queue;
- D1;
- Admin.

D1 migration НЕ НУЖНА.
