TUNEWRAP — STAGE 12.14.7
PUBLIC PRICING + TERMS I18N

ЧТО ИСПРАВЛЕНО

На публичном сайте блоки «Стоимость и форматы», «Свадебный формат»,
карточки тарифов и окно «Подробнее» могли оставаться на русском при выбранном
EN, UA, GE или DE. В футере ссылка «Условия использования» также могла
оставаться русской.

Причина: live Pricing/Site CMS подставлял русский текст как запасной и затирал
уже существующий правильный встроенный перевод выбранного языка.

Stage 12.14.7 вводит единое правило:

  точный язык CMS → встроенный перевод того же языка.

Текст другого языка больше не может подменить выбранный язык интерфейса.

Проверены EN / RU / UA / GE / DE для:

- заголовка и описания блока стоимости;
- названий и состава обычных тарифов;
- акции и кнопок «Подробнее»;
- свадебного блока и свадебных пакетов;
- полного окна каждого тарифа;
- выбора пакета внутри формы заказа;
- подарочного сертификата;
- данных пакета при отправке заказа;
- ссылки и заголовка «Условия использования» в футере.

Цены, порядок и видимость тарифов по-прежнему берутся из live Pricing CMS.
Песни, их переводы, Admin, MP3, обложки, публикация и черновики не менялись.
D1 migration не требуется.

УСТАНОВКА

1. Распакуйте ZIP прямо в корень папки website с заменой файлов.
2. Откройте PowerShell в папке website.
3. Выполните:

   node scripts/install-stage-12.14.7-public-pricing-terms-i18n.js

Ожидаемый первый результат:

   PASS: Stage 12.14.7 Public Pricing and Terms I18N installed.

ПОСЛЕ PASS

Запустите полный тест:

   npm.cmd test

Затем сборку Cloudflare:

   npx.cmd wrangler pages functions build

Ожидаемый итог:

   Compiled Worker successfully

В GitHub Desktop удалите из Changes только автоматически созданный
_worker.bundle через Discard Changes. Все остальные файлы Stage 12.14.7
оставьте, сделайте Commit to main, Push origin и дождитесь зелёного deploy.

ПРОВЕРКА НА САЙТЕ

После зелёного deploy нажмите Ctrl+F5 и последовательно включите
EN, RU, UA, GE и DE.

Для каждого языка проверьте:

1. «Стоимость и форматы».
2. Обычные тарифы и окно «Подробнее».
3. «Свадебный формат» и его карточки.
4. Внизу сайта ссылку «Условия использования».

Все подписи должны быть на выбранном языке. Цены должны остаться текущими.
