TUNEWRAP — STAGE 12.12.1
PAYMENT SECTION VISIBILITY

Да, это именно отдельный переключатель ВСЕГО блока оплаты.

ADMIN → САЙТ → СПОСОБЫ ОПЛАТЫ

Появляется:
[✓] Показывать весь блок оплаты на сайте

Если снять галочку и сохранить:
- вся публичная карточка «Способы оплаты» исчезает;
- ссылка «Оплата» в нижней навигации также исчезает;
- сами настройки/карточки оплаты в Admin НЕ удаляются.

Можно через день/неделю снова включить галочку → Save → блок вернётся.

Кроме того:
если глобальный переключатель включён, но нет ни одной включённой карточки оплаты,
пустой блок на сайте автоматически НЕ показывается.
То есть ситуация «карточка висит, а платить нечем» больше невозможна.

Если позже будут PayPal / карта / TBC:
каждый способ всё ещё отдельно имеет:
[✓] Показывать карточку

Таким образом два уровня:
1. ВЕСЬ БЛОК оплаты ON/OFF.
2. КАЖДЫЙ способ оплаты ON/OFF.

D1 migration НЕ НУЖНА.
Настройка хранится в существующем Site CMS config_json.

Установка:
1. Распаковать ZIP поверх website.
2. node scripts/install-stage-12.12.1-payment-section-visibility.js
3. node scripts/stage-12.12.1-payment-section-test.js
4. npm.cmd test
5. npx.cmd wrangler pages functions build

После PASS:
restore _worker.bundle

GitHub Desktop Summary:

Commit to main → Push origin.

После деплоя:
Admin → Сайт → Способы оплаты
снять «Показывать весь блок оплаты на сайте»
→ Сохранить изменения.
