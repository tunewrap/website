TUNEWRAP — STAGE 12.14.2
INCREMENTAL ADMIN EDITOR

ВАЖНО
Stage 12.14.1 отдельно ставить НЕ НУЖНО. 12.14.2 включает его media fix и дополнительно
исправляет реальную text-only проблему.

ЧТО ОБНАРУЖЕНО ПОСЛЕ TEXT-ONLY ЗАВИСАНИЯ
Пользователь не выбирал новую обложку и не загружал MP3.
Значит R2 upload не мог быть причиной именно этого зависания.

В текущем Admin есть две независимые проблемы:

1. closeEditor() содержит:
   if(state.busy)return;
   Поэтому во время любого зависшего PATCH редактор невозможно закрыть.

2. api() / persist() не имеют editor-scoped timeout/cancel.
   Если PATCH / publish запрос не завершился, Admin остаётся busy без выхода.

Stage 12.14 уже оставил Preview активным, но не оставил активной кнопку выхода и
не сделал текущую транзакцию отменяемой.

КАК ДОЛЖЕН РАБОТАТЬ РЕДАКТОР ПОСЛЕ 12.14.2
- только текст -> сохраняется только metadata PATCH;
- только описание -> сохраняется metadata PATCH;
- без текста -> допустимо;
- без новой обложки -> старая обложка остаётся, upload не запускается;
- новая обложка -> только тогда запускается cover upload;
- без нового MP3 -> старый MP3 остаётся, upload не запускается;
- новый MP3 -> только тогда запускается audio upload;
- можно редактировать постепенно и сохранять после каждого шага;
- Workers AI не блокирует сохранение;
- «Назад» остаётся доступной даже во время операции и отменяет зависший запрос;
- metadata запрос автоматически разблокирует интерфейс через 20 секунд;
- upload автоматически разблокирует интерфейс через 120 секунд;
- R2 tee deadlock также исправлен на случай будущей замены обложки/MP3.

ПУБЛИКАЦИЯ
Для публикации по-прежнему нужен MP3. Для черновика MP3 не обязателен.
Название / раздел / язык остаются базовыми обязательными полями записи.
Описание, текст песни, перевод, обложка и новый MP3 НЕ обязательны для постепенного редактирования.
