TUNEWRAP — STAGE 12.14.10
MOBILE / TABLET PULL-TO-REFRESH

ЧТО ИСПРАВЛЕНО

На телефоне и планшете сайт использовал отдельный фиксированный контейнер
.app-scroll. Старые правила overscroll-behavior:none/contain обрывали жест на
этом контейнере, поэтому страницу нельзя было потянуть вниз и обновить обычным
жестом браузера.

Stage 12.14.10 возвращает вертикальную цепочку прокрутки браузеру на сенсорных
устройствах до 1024 px. На первом экране пользователь снова может потянуть сайт
вниз и отпустить для штатного обновления Chrome/Safari.

НЕ ИЗМЕНЕНО

- экранное вертикальное перелистывание мобильного интерфейса;
- горизонтальные карточки и фильтры;
- внутренние прокрутки каталогов, форм и модальных окон;
- Full Player, Mini Player, seek и очередь;
- Stage 12.14.9 — фоновая проверка новой версии и данных Admin/D1;
- Admin, переводы, D1 и R2.

УСТАНОВКА

Распакуйте ZIP прямо в корень website с добавлением новых файлов.
Затем выполняйте команды по одной:

node scripts/install-stage-12.14.10-mobile-pull-refresh.js
npm.cmd test
npx.cmd wrangler pages functions build

После сборки удалите из Changes только _worker.bundle, закоммитьте остальные
файлы, выполните Push origin и дождитесь зелёного Cloudflare.

ПРОВЕРКА ПОСЛЕ ДЕПЛОЯ

1. Один раз откройте свежую версию сайта на телефоне.
2. На главном экране, находясь в самом верху, потяните страницу пальцем вниз.
3. Должен появиться штатный индикатор обновления браузера, после отпускания
   страница загружается заново.

D1 migration: not required.
