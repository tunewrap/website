TUNEWRAP — STAGE 12.14.5
GERMAN TRANSLATION ADAPTATION

ПРОБЛЕМА

После Stage 12.14.4 все языки переводились и сохранялись правильно, но DE мог
принять уже готовую английскую строку за немецкую. Оба языка используют
латиницу, поэтому общей проверки письменности для этого различия недостаточно.

ЧТО ИСПРАВЛЕНО

1. Для немецкого добавлена отдельная EN/DE проверка.
   Английские служебные слова больше не принимаются за немецкий текст.

2. При создании DE-строки уже готовая EN-строка передаётся только как
   контрольный образец. Если модель вернула тот же английский текст, ответ
   отклоняется и используется следующий способ перевода.

3. Уже сохранённый английский текст в DE распознаётся автоматически.
   После повторного «Опубликовать» немецкая версия создаётся заново.

4. Короткие имена и фирменные фразы не повреждаются.
   Например, Diana и Our Way. Our Choice. могут оставаться без перевода.

5. Изменение изолировано от RU / UA / GE / EN.
   Сохранение отдельных полей, черновик, публикация, MP3 и обложка не менялись.

УСТАНОВКА

1. Распакуйте ZIP прямо в корень папки website.
2. В PowerShell из папки website выполните:

   node scripts/install-stage-12.14.5-german-translation-adaptation.js

3. Ожидаемый итог:

   PASS: Stage 12.14.5 German Translation Adaptation installed.
   D1 migration: not required.

4. Затем выполните:

   npm.cmd test

5. После публикации через GitHub Desktop откройте Admin с Ctrl+F5.
   Откройте нужный трек и ничего не меняя нажмите «Опубликовать».
   Админка обнаружит английский текст в DE и заменит только немецкую версию.

ВАЖНО

- Ничего вручную в D1 удалять не нужно.
- Миграция D1 не требуется.
- Остальные языки повторно не переводятся, если они уже корректны.
- MP3 и обложку повторно загружать не нужно.
