TUNEWRAP — STAGE 12.14.8
NATIVE HOMEPAGE ANNOUNCEMENT I18N

ЧТО ИСПРАВЛЕНО

Верхнее объявление «СКОРО СТАРТ!» показывалось только на RU.
На EN, UA, GE и DE весь блок объявления исчезал.

Причина: переключатель, даты и период показа объявления общие для сайта,
а метка и текст этого объявления были заполнены в Site CMS только для RU.
После правильного запрета межъязыковой подстановки Stage 12.14.7 публичный
runtime больше не имел права показывать русский текст на другом языке и
скрывал пустой блок.

Stage 12.14.8 добавляет проверенные нативные варианты текущего стартового
объявления:

  EN — COMING SOON!
  RU — СКОРО СТАРТ!
  UA — НЕЗАБАРОМ СТАРТ!
  GE — მალე ვიწყებთ!
  DE — BALD GEHT ES LOS!

Текст и даты отображаются на выбранном языке. Точный текст из CMS выбранного
языка всегда имеет приоритет.

ВАЖНАЯ ЗАЩИТА

Исправление относится только к известному текущему стартовому объявлению.
Произвольное новое русское объявление не будет автоматически подставляться
на EN, UA, GE или DE и не сможет смешать языки сайта.

В Admin Studio → Сайт под редактором объявления теперь показывается
предупреждение, если объявление включено, но какие-то языки не заполнены.
Перед изменением текущего текста заполните или автопереведите EN/RU/UA/GE/DE.

Тарифы, условия, песни, переводы песен, заказы, MP3, обложки, черновики и
публикация не менялись. D1 migration не требуется.

УСТАНОВКА

1. Распакуйте ZIP прямо в корень папки website с заменой файлов.
2. Откройте PowerShell в папке website.
3. Выполните:

   node scripts/install-stage-12.14.8-announcement-native-i18n.js

Ожидаемый первый результат:

   PASS: Stage 12.14.8 Announcement Native I18N installed.

ПОСЛЕ PASS

Запустите полный тест:

   npm.cmd test

Затем сборку Cloudflare:

   npx.cmd wrangler pages functions build

Ожидаемый итог:

   Compiled Worker successfully

В GitHub Desktop удалите из Changes только автоматически созданный
_worker.bundle через Discard Changes. Все остальные файлы Stage 12.14.8
оставьте, сделайте Commit to main, Push origin и дождитесь зелёного deploy.

ПРОВЕРКА НА САЙТЕ

После зелёного deploy нажмите Ctrl+F5. Затем последовательно откройте:

  https://tunewrap.studio/
  https://tunewrap.studio/?lang=ru
  https://tunewrap.studio/?lang=uk
  https://tunewrap.studio/?lang=ka
  https://tunewrap.studio/?lang=de

На всех пяти языках верхний баннер должен быть видим. Его метка, текст и
формат дат должны соответствовать выбранному языку.
