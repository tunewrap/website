TUNEWRAP — STAGE 12.14.6
COMPLETE LOCALE MATRIX

ЧТО ИСПРАВЛЕНО

Песня может иметь любой исходный язык: RU, UA, GE, EN или DE.
Название, описание/история и текст песни должны независимо достраиваться
на каждый из остальных языков интерфейса.

Раньше уже опубликованный трек без новых изменений не запускал перевод,
если целевой язык был просто пустым. Поэтому при ?lang=de публичный плеер
показывал английский запасной текст, хотя немецкого перевода в карточке не было.

Stage 12.14.6 исправляет именно этот пробел:

- повторное «Опубликовать» или «Сохранить черновик» возобновляет недостающие переводы;
- отдельно проверяются название, описание и текст песни;
- проверка работает для всей матрицы RU/UA/GE/EN/DE;
- английский fallback больше не считается готовым немецким переводом;
- существующие правильные переводы не перезаписываются;
- сохранение полей, MP3, обложки, черновика и публикации не менялось;
- D1 migration не требуется.

УСТАНОВКА

1. Распакуйте ZIP прямо в корень папки website с заменой файлов.
2. Откройте PowerShell в папке website.
3. Выполните одну команду:

   node scripts/install-stage-12.14.6-complete-locale-matrix.js

Ожидаемый результат начинается так:

   PASS: Stage 12.14.6 Complete Locale Matrix installed.

ПРОВЕРКА ПРОЕКТА

После PASS выполните:

   npm test

Затем:

   npx.cmd wrangler pages functions build

Ожидаемый итог сборки:

   Compiled Worker successfully

В GitHub Desktop удалите из списка изменений только автоматически созданный
_worker.bundle через Discard Changes. Остальные файлы Stage 12.14.6 оставьте,
сделайте Commit to main, Push origin и дождитесь зелёного Cloudflare deploy.

ПРОВЕРКА НА САЙТЕ

1. Откройте Admin и обновите страницу через Ctrl+F5.
2. Откройте нужный уже опубликованный трек.
3. Ничего менять не обязательно: нажмите «Опубликовать».
4. Дождитесь сообщения о завершении/проверке переводов.
5. Откройте трек с ?lang=de и обновите Ctrl+F5.
6. Название, описание и текст песни должны быть на немецком.

Для нового или отредактированного трека действует та же общая логика:
исходный язык песни может быть любым, а контент отображается на выбранном
пользователем языке сайта.
