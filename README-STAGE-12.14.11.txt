TUNEWRAP — STAGE 12.14.11
MOBILE PULL-TO-REFRESH CONTROL

ПОЧЕМУ STAGE 12.14.10 БЫЛО НЕДОСТАТОЧНО

Проверка на реальном Android показала: одного overscroll-behavior:auto мало.
Мобильный TuneWrap работает внутри фиксированного .app-scroll, а html/body имеют
overflow:hidden. Поэтому браузерный viewport не получает жест и Chrome не
показывает свой индикатор обновления.

ЧТО ДЕЛАЕТ STAGE 12.14.11

На телефоне, только на самом верху главного экрана:

1. Пользователь тянет контент вниз.
2. Страница следует за пальцем и показывает индикатор на текущем языке.
3. После достаточного движения текст меняется на «Отпустите для обновления».
4. После отпускания выполняется свежая загрузка с параметром tw-refresh,
   поэтому старый HTML не может вернуться из кэша.

ЗАЩИТА ОТ КОНФЛИКТОВ

- горизонтальный жест не перехватывается;
- если внутренний блок прокручен, pull-to-refresh не запускается;
- ниже первого экрана жест не запускается;
- открытые плееры, библиотеки и модальные окна не затрагиваются;
- стандартные вертикальные переходы продолжают работать;
- тексты индикатора есть на EN/RU/UA/GE/DE;
- на планшетах с обычной прокруткой остаётся штатное обновление браузера.

УСТАНОВКА

Распакуйте ZIP в корень website и выполняйте по одной:

node scripts/install-stage-12.14.11-mobile-pull-refresh-control.js
npm.cmd test
npx.cmd wrangler pages functions build

После сборки удалите из Changes только _worker.bundle, закоммитьте остальные
файлы, выполните Push origin и дождитесь зелёного Cloudflare.

ПРОВЕРКА

Откройте свежую версию сайта на телефоне. На главном экране прокрутите контент
в самый верх, потяните его вниз на несколько сантиметров и отпустите после
появления надписи «Отпустите для обновления».

D1 migration: not required.
