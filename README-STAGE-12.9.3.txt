TUNEWRAP WEB — STAGE 12.9.3
TRUE HOLD DRAG

Причина найденa точно.

В 12.9.2 во время drag мы делали:
  list.insertBefore(row, ...)
то есть физически переставляли в DOM САМУ строку, которая держала pointer capture.

Chrome при первом таком DOM-переносе сбрасывал pointer capture.
Из-за этого drag завершался после первого соседнего трека.
Именно поэтому визуально стало быстрее, но всё равно только на один шаг.

12.9.3 это меняет архитектурно.

Теперь при зажатии:
1. Настоящая строка трека остаётся тем же DOM-элементом.
2. Она становится position:fixed и сама летит за курсором.
3. В списке создаётся отдельный placeholder «Отпустить здесь».
4. Во время движения перемещается ТОЛЬКО placeholder.
5. Pointer capture остаётся у трека всё время.
6. Можно протащить #2 → #5 → #10 → #15, не отпуская мышь.
7. У края экрана работает auto-scroll.
8. Только на pointerup настоящий трек вставляется в выбранный placeholder.
9. После этого активируется «Сохранить порядок».

На компьютере можно схватить:
- золотую ручку ⠿;
- или любую свободную часть строки трека.

Кнопки ↑ ↓ / preview / edit не запускают drag.

На touch используется ручка, чтобы обычный скролл страницы не ломался.

Stories и Author независимы.
Стрелки остаются fallback.
D1 migration НЕ НУЖНА.
API не меняется.

- сохранить.
