TUNEWRAP — STAGE 12.14.4
TRANSLATION INTEGRITY + REPAIR

ЧТО ИСПРАВЛЕНО

1. Устранена причина «каши» в переводах.
   Когда основной переводчик возвращал пустую строку, резервная reasoning-модель
   могла вернуть своё внутреннее англоязычное объяснение. Раньше оно принималось
   за перевод и целиком сохранялось в D1.

2. Резервные модели заменены на модели с JSON Mode.
   Ответ принимается только в строгом поле translation.

3. Перед возвратом перевода сервер проверяет:
   - отсутствие рассуждений, объяснений, markdown и многострочного ответа;
   - разумную длину относительно исходной строки;
   - соответствие письменности целевому языку RU / UA / GE.
   Небезопасный ответ никогда не записывается в каталог.

4. Админка распознаёт уже испорченные локализации.
   После повторного «Сохранить черновик» или «Опубликовать» такой перевод
   считается отсутствующим и создаётся заново.

5. Каждый язык сохраняется независимо.
   Если следующий язык временно не перевёлся, уже готовые языки остаются
   исправленными. Повторное сохранение продолжит восстановление.

6. Сохранены все гарантии Stage 12.14.3:
   любое одно поле, MP3, обложка, черновик и публикация работают независимо.

УСТАНОВКА

1. Распакуйте ZIP прямо в корень папки website.
2. Откройте PowerShell в папке website.
3. Выполните:

   node scripts/install-stage-12.14.4-translation-integrity.js

4. Ожидаемый итог:

   PASS: Stage 12.14.4 Translation Integrity installed.
   D1 migration: not required.

5. Затем выполните:

   npm.cmd test

6. После публикации через GitHub Desktop откройте Admin с Ctrl+F5.
   Откройте «Диана!» и просто нажмите «Опубликовать» ещё раз.
   Админка сама обнаружит и заменит испорченные UA / GE / EN / DE версии.
   Подождите уведомление «переводы проверены и исправлены», затем обновите сайт.

ВАЖНО

- Ничего вручную в D1 удалять не нужно.
- Миграция D1 не требуется.
- MP3 и обложку повторно загружать не нужно.
- Если закончился дневной лимит Workers AI, уже исправленные языки сохранятся.
  Позже снова нажмите «Опубликовать», чтобы продолжить оставшиеся языки.
