TUNEWRAP WEB — STAGE 12.6: ORDER INTAKE COMPLETION

ЧТО ИСПРАВЛЯЕТ ЭТОТ ЭТАП

1. АВТОПЕРЕВОД ЗАЯВОК В ADMIN
Если заявка пришла на UA / GE / EN / DE:
- оригинал сохраняется без изменений;
- при первом открытии заказа Admin Studio автоматически переводит:
  • событие;
  • уточнение события;
  • главное в истории;
  • описание;
  • дополнительные вопросы и ответы;
- перевод показывается отдельным блоком «Перевод на русский»;
- результат кэшируется в D1 и при следующем открытии не переводится заново;
- если Workers AI временно недоступен — оригинал остаётся доступным, появляется кнопка «Повторить перевод».

RU-заявки не переводятся.

2. ОБЯЗАТЕЛЬНОЕ ПОЛЕ ВОКАЛА
В анкете появляется:
«Кто должен петь?»

Варианты:
- Мужской голос
- Женский голос
- Мужчина + женщина
- Неважно / на усмотрение TuneWrap

Для обычной и свадебной песни поле обязательно.
Для сертификата остаётся упрощённый сценарий.

В Admin → Заказы появляется отдельная карточка «Вокал».
В Suno-основу добавляется стабильная EN-подсказка: male vocal / female vocal / male and female duet / flexible.

3. ВСЕ 6 ПАКЕТОВ ПРЯМО В АНКЕТЕ
Один селектор «Пакет и стоимость» показывает:
- 3 обычных пакета из Pricing CMS;
- 3 свадебных пакета из Pricing CMS.

Никаких захардкоженных названий/цен.
Если вы изменили название или стоимость в Admin → Стоимость, анкета получает новые данные автоматически.

Каждый пункт отображается как:
НАЗВАНИЕ ПАКЕТА — $ЦЕНА

В summary также:
НАЗВАНИЕ ПАКЕТА ($ЦЕНА)

4. НИЖНЯЯ НАВИГАЦИЯ
Исправляются:
- Философия TuneWrap
- Как это работает
- Музыкальные истории
- Стоимость и форматы
- Авторские песни
- Рассказать свою историю
- Свадебный формат
- Контакты
- Оплата

«Корпоративные клиенты» и «Условия использования» сохраняют существующую рабочую логику.
«Написать нам» остаётся внешним контактом из Site CMS.

УСТАНОВКА
1. Распаковать ZIP поверх корня website.
2. Выполнить:
   node scripts/install-stage-12.6-order-intake-completion.js
3. Применить D1 migration:
   npx.cmd wrangler d1 execute tunewrap-catalog --remote --file=./migrations/0007_order_translation_vocal.sql
4. Проверить:
   npx.cmd wrangler d1 execute tunewrap-catalog --remote --command="SELECT key,value FROM cms_meta WHERE key='ordersSchemaVersion';"
5. Тест этапа:
   node scripts/order-intake-completion-test.js
6. Общий тест:
   npm.cmd test
7. Build:
   npx.cmd wrangler pages functions build
8. Restore _worker.bundle.
9. GitHub Desktop:
   Stage 12.6 – Order Intake Completion
   Commit to main → Push origin.
